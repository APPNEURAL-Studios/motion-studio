# Motion Studio

Animation, GIF, Lottie, motion graphics

Create 2D animations, motion graphics, and frame-by-frame sequences. Animate logos, kinetic typography, and whiteboard explainers, build Lottie and GIF animations, and fine-tune keyframes, timelines, transitions, and presets.
